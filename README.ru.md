# MoveSense

Перенос файлов и папок с проверкой ссылок на них. Приложение показывает,
какие пути изменятся, исправляет поддерживаемые ссылки в Markdown и JSON
и сохраняет журнал для отмены переноса.

[Скачать](https://github.com/DOPIAS/MoveSense/releases) · [English](README.md)

![MoveSense](docs/images/main.png)

## Как пользоваться

1. Распакуйте portable-архив и запустите `MoveSense.exe`.
2. Перетащите файл или папку в окно и выберите папку назначения.
3. Проверьте результат и нажмите **Перенести сюда**.

После переноса можно нажать **Вернуть обратно**. Предыдущие операции доступны
в истории. По умолчанию проверяется и родительская папка: её путь виден,
проверку можно отключить. Дополнительные места поиска и переименование
находятся в раскрывающемся разделе параметров.

## Через правую кнопку мыши

Один раз нажмите **Включить ПКМ** на главном экране. Затем нажмите правой
кнопкой на файл или папку на рабочем столе либо в Проводнике и выберите
**Перенести через MoveSense**. Сразу откроется выбор папки назначения.
В Windows 11 команда находится в меню **Показать дополнительные параметры**.

В настройках можно создать ярлык на рабочем столе и перетаскивать файлы на него.
Если перенесли само приложение, обновите меню из новой копии.

## Ограничения

Это предварительная версия для Windows x64. Portable-сборка содержит .NET,
устанавливать его отдельно не нужно. Цифровой подписи у сборок нет.

- Перенос работает в пределах одного диска. Перезапись существующих файлов,
  сетевые папки и символические ссылки не поддерживаются.
- Автоматически исправляются поддерживаемые пути в Markdown и JSON.
  Ссылки в конфигурациях, проектах и ярлыках показываются для ручной проверки.
- Ссылки за пределами выбранных папок и внутри баз данных не проверяются.
- Отмена не перезаписывает новые изменения. Журнал хранит исходные версии
  исправляемых документов, но не заменяет резервную копию переносимых файлов.
