# Security

MoveSense is an early preview. Keep independent backups of important files.

Report vulnerabilities through the repository's private security reporting
when available. Include a minimal synthetic reproduction, the version and
operating system. Do not publish sensitive file paths, documents, journals
or database contents in public issues.

Review proposed repairs before executing them. MoveSense does not execute
scripts found while scanning or load external detector plugins. Explorer
integration is opt-in and applies only to the current Windows account.

See [safety and recovery](docs/safety.md) for the guarantees and limits.
