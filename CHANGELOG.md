# Changelog

## 0.2.1

First public preview.

- Move a file or folder by choosing its destination, dropping it into the app,
  or opening it from Explorer's right-click menu.
- Preview incoming and outgoing references; repair supported Markdown and JSON paths.
- Review selected configuration, project and Windows shortcut references.
- Reject overwrites, cross-volume moves, junctions and stale analysis.
- Save recovery journals and original reference bytes; undo from the result or History.
- Create a desktop shortcut and manage per-user Explorer integration.
- Support English and Russian, with system, light and dark themes.
- Package a self-contained Windows x64 portable app and a per-user installer.
